# m04.01 — Client Runtime
_Parent: [`m04-resilient-client.md`](m04-resilient-client.md)_
_Status: Complete 2026-09-16_

## Goal

Establish the browser-owned application runtime, authenticated data boundary, and shared interface foundation that every migrated surface uses.

## Worklists

1. [x] **Client foundation**
   1. [x] Add React and TypeScript dependencies, manifests, and locked versions inside Docker.
   2. [x] Configure Phoenix esbuild for TSX and run `tsc --noEmit` for type checking.
   3. [x] Run pure client tests with `node:test` and include them in precommit.
   4. [x] Add a direct Brave/Chrome CDP harness that loads the real app and performs one interaction.
   5. [x] Connect through Phoenix Channels and apply one live update through the production path.

2. [x] **Bootstrap and session** — correct theme from first paint.
   1. [x] Serve one minimal bootstrap document and production asset entry point without product-shaped server-rendered controls.
   2. [x] Initialize the signed-in identity and CSRF/session boundary without storing an API bearer token in the browser.
   3. [x] Show explicit loading, asset-load failure, and client-startup failure states with recovery.
   4. [x] Show expired-session and forbidden states with appropriate recovery.
   5. [x] Make the first painted control interactive within the §6 budget.

3. [x] **State and routing** — preserve history, back/forward, scroll, and focus.
   1. [x] Keep typed domain state, recovery state, preferences, and ephemeral UI state separate.
   2. [x] Resolve existing paths on direct load and client navigation, preserving deep links and refresh.
   3. [x] Add account-scoped IndexedDB with schema versioning and account isolation.
   4. [x] Bound IndexedDB growth with quota handling and cleanup.
   5. [x] Purge IndexedDB on logout and recover safely from a corrupt or unavailable store.
   6. [x] Preserve navigation-level session, subscriptions, and presence continuity.

4. [x] **Shared interface foundation** — preserve the existing UX baseline without layout shifts.
   1. [x] Implement the application frame, navigation, and rails/panes once for all routes.
   2. [x] Implement shared dialogs, menus, and forms.
   3. [x] Implement shared notices, connection summary, and loading/error feedback.
   4. [x] Make navigation actions visibly button-like, with consistent open, active, pressed, disabled, hover, and focus states.
   5. [x] Restore the account menu in the client frame: avatar, then Account details, Preferences, Sign out, as the LiveView header has it.
   6. [x] Restore the notifications bell in the client frame.
      1. [x] Add a browser-private read for the user's recent notifications and unread count.
      2. [x] Push new notifications to the client over its socket.
      3. [x] Render the bell with its unread dot and flyout; opening it marks notifications read through the existing operation.
   7. [x] Keep the theme control as the three-way System/Light/Dark segmented toggle; it is exempt from item 4.

5. [x] **Authenticated client data boundary** — browser-session and public API credentials never cross.
   1. [x] Reuse serializers, authorization, domain contexts, and the operations engine behind session-authenticated browser reads and writes.
   2. [x] Add only the read/session endpoints or channel calls the inventory proves are missing; do not fork business logic for the browser.
   3. [x] Standardize success, validation, authorization, stale-session, and transport errors for client consumption.

6. [x] **Testing**
   1. [x] [Agent] Test bootstrap, first-paint theme, loading/startup failures, session expiry, and forbidden recovery.
   2. [x] [Agent] Test routing, history, deep links, refresh, scroll, focus restoration, and IndexedDB migration/failure/logout.
   3. [x] [Agent] Test shared controls, both themes, and narrow/desktop layouts.
   4. [x] [Agent] Test keyboard, focus, accessible naming, reduced motion, and no-layout-shift behavior for shared primitives.
   5. [x] [Agent] Verify every action introduced here meets `UX_GUARDRAILS.md` §6 under latency and disconnected startup.
   6. [x] [Agent] Confirm every endpoint, operation, or field added here has current prose in [`agent_surfaces.md`](../../reference/agent_surfaces.md).
   7. [x] [Agent] Test that browser-session and public API credentials cannot cross authorization boundaries.
   8. [x] [Human] Check the header between tablet and small-desktop widths, where the nav, theme toggle, bell, and avatar share one row and no automated check measures it.

## Exit

The browser runtime can own a route from bootstrap through authenticated reads, writes, errors, navigation, and recovery without LiveView DOM rendering.
